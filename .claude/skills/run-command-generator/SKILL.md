---
name: run-command-generator
description: 將目前的敘述文字、選取內容或需求描述，建立為 Claude Code 自訂命令（.claude/commands/*.md）。當使用者要求「把這段建立成命令」、「建立 xxx 命令」時使用。
---

(1). 判斷要作為命令內容的敘述文字來源，依優先順序：
   a. 使用者在本次要求中明確提供的文字內容。
   b. 目前選取（selection）的文字。
   c. 對話中最近討論、使用者指稱的敘述段落。
(2). 判斷命令名稱：
   a. 若使用者有指定名稱，轉為 kebab-case（全小寫、以 - 連接）後使用。
   b. 若未指定，依內容主題建議一個簡短的 kebab-case 名稱，並與使用者確認。
(3). 確認專案根目錄下的 `.claude/commands/` 目錄存在，不存在則建立。
(4). 若 `.claude/commands/<name>.md` 已存在，先向使用者確認是否覆蓋，不可未經確認直接覆寫既有命令。
(5). 於 `.claude/commands/<name>.md` 建立檔案，格式如下：

    ---
    description: <一句話摘要此命令用途>
    ---

    <完整敘述內容，原文保留，不需改寫或摘要>

(6). 完成後回報使用者：建立的檔案路徑，以及日後可用 `/<name>` 呼叫此命令。
