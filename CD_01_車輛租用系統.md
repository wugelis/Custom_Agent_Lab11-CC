# CD_01 車輛租用系統 — Class Diagram

```mermaid
classDiagram
    class VehicleType {
        <<enumeration>>
        Car
        SUV
        Truck
        SportsCar
        ElectricCar
    }

    class Account {
        +username : String
        +password : String
        +email : String
        +RegisterAccount(username : String, password : String, email : String) Boolean
        +Login(username : String, password : String) Boolean
    }

    class RentalOrder {
        +orderId : String
        +status : String
        +ToRentalCar(vehicleType : VehicleType, startDate : Date, endDate : Date) Boolean
        +ConfirmRental() Boolean
    }

    class Vehicle {
        +vehicleType : VehicleType
        +SelectCarType(vehicleType : VehicleType) Vehicle
    }

    class RentalPeriod {
        +startDate : Date
        +endDate : Date
        +SelectPeriod(startDate : Date, endDate : Date) RentalPeriod
    }

    class RentalFee {
        +totalFee : Float
        +CalculateFee(vehicle : Vehicle, period : RentalPeriod) Float
    }

    RentalOrder --> Account : 由已登入帳戶建立
    RentalOrder --> Vehicle : 租用車輛
    RentalOrder *-- RentalPeriod : 包含租用時間區間
    RentalOrder *-- RentalFee : 包含租金
    Vehicle --> VehicleType : 車型分類
    RentalFee ..> Vehicle : 依車型計價
    RentalFee ..> RentalPeriod : 依時間區間計價
```

---

## 補充說明

| Class 名稱 | 中文名稱 | 職責說明 |
|------------|----------|----------|
| Account | 帳戶 | 負責註冊帳號與登入驗證。 |
| RentalOrder | 租車訂單 | 協調線上租車流程 ToRentalCar()，並負責確認租車 ConfirmRental()。 |
| Vehicle | 車輛(車型) | 負責選擇車型，車型為 Car、SUV、Truck、SportsCar、ElectricCar。 |
| RentalPeriod | 租用時間區間 | 記錄並選定租用起訖日期。 |
| RentalFee | 租金 | 依車型與租用時間區間計算租金。 |
| VehicleType | 車型列舉 | 列舉型別（非 Domain Object），定義可選車型。 |
